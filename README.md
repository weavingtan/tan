# tan

微信公众号 Markdown 排版工作台：<https://weavingtan.github.io/tan/>

## 这是什么

在浏览器里把 Markdown 转成可直接粘贴进微信公众号后台的内联样式富文本。解析、样式内联、排版合规体检与自愈全部在你的浏览器内完成，没有服务端，正文不会离开本机。

## 关于本仓库

- 本仓库**只存放构建产物**，源码在私有仓库中，不在此处。
- `gh-pages` 分支是站点的发布源，由源码仓库的 `npm run deploy:playground` 整体覆盖推送。**不要手动修改该分支下的文件**，任何手动改动都会在下次发布时被覆盖。
- `main` 分支只有这份说明与许可证。
